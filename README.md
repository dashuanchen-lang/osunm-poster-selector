# 奥森姆海报模板选型册

纯静态客户预览页，可直接部署到 GitHub Pages 仓库根目录。所有网页路径均为相对路径，支持 Pages 仓库子路径。

## 本地预览

在本目录启动静态服务器：

```powershell
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。测试：`node --test tests/*.test.cjs`。

## 内容边界

- 页面包含 OSM-01 至 OSM-19 的 19 个模板和 34 张精选案例优化副本。
- 每个模板只归属一个主产品类别，工程表达和详情页长图另用标签/形式筛选；分类按钮显示该类模板数量。
- OSM-07 卡片用模块预览封面展示；详情弹层展示完整长图案例。
- 案例仅说明历史构图，旧文案、型号、参数、二维码、联系方式和标记不会自动迁移。
- 站点不包含完整 155 张原图或工作流源文件。
